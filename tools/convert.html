Buka lewat tautan, bukan dari folder

Halaman ini tidak bisa dibuka dengan klik ganda, karena browser memblokir kode pemeriksa jika dibuka langsung dari disk.

Buka dengan salah satu cara berikut:

  • Tautan Netlify aplikasi, lalu tambahkan /tools/convert.html di belakangnya. Contoh: https://nama-situs.netlify.app/tools/convert.html.
  • Server lokal (lihat README bagian Menjalankan), lalu buka http://localhost:8000/tools/convert.html.

Pemeriksa dan konverter materi

Untuk tim konten. Tidak perlu memasang apa pun. File tidak diunggah ke mana pun: semua pemeriksaan berjalan di browser ini.

  1. Di Google Sheets, unduh kelima tab satu per satu, dengan urutan wilayah, kanji, kotoba, quest, percakapan: buka tabnya, lalu File → Download → Comma Separated Values (.csv). Google Sheets hanya mengunduh tab yang sedang dibuka.
  2. Pilih kelima file CSV sekaligus di bawah (tahan Ctrl, di Mac Cmd, sambil mengklik), isi nama revisi, lalu tekan Periksa.
  3. Perbaiki semua error di spreadsheet, unduh ulang CSV-nya, dan periksa lagi.
  4. Jika lolos, tekan Unduh content.json dan serahkan file itu ke pengelola aplikasi.

Nama file tidak penting: jenis tab dikenali dari baris judulnya.

Tetap draft-0 sampai semua nomor bab diperiksa terhadap buku. Setelah itu, misalnya rev-1.
