Buka lewat server lokal

Aplikasi ini tidak bisa dibuka dengan klik ganda pada index.html. Browser memblokir pemuatan file materi (data/content.json) langsung dari disk. Pilih salah satu cara berikut.

Cara 1 — VS Code + Live Server

  1. Buka folder proyek ini di VS Code (File → Open Folder…).
  2. Buka panel Extensions (Ctrl+Shift+X, di Mac Cmd+Shift+X), cari Live Server (pembuat: Ritwick Dey), lalu klik Install.
  3. Klik kanan index.html di panel Explorer, pilih Open with Live Server.
  4. Browser terbuka otomatis di alamat seperti http://127.0.0.1:5500.

Cara 2 — Terminal (Python)

  1. Buka Terminal di folder proyek, yaitu folder yang berisi index.html.
  2. Jalankan perintah ini: 
    python3 -m http.server 8000
    Di Windows, jika perintah di atas tidak dikenal, gunakan python -m http.server 8000.
  3. Buka http://localhost:8000 di browser.
  4. Untuk berhenti, tekan Ctrl+C di Terminal.

Cara 3 — Versi online

Jika aplikasi sudah di-deploy ke Netlify, cukup buka tautan Netlify-nya.

Aplikasi gagal dimuat

Browser tidak bisa menjalankan aplikasi. Coba muat ulang halaman. Jika masih gagal, gunakan Chrome, Safari, Firefox, atau Edge versi terbaru.
